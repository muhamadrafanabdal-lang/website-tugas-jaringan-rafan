Perakitan Kabel Crossover

Langkah membuat kabel LAN jenis crossover

1

Kupas Kabel

Kupas kulit kabel UTP/STP kurang lebih sepanjang dua ruas jari telunjuk menggunakan stripper.

2

Susun Kabel

Susun kabel berdasarkan urutan warna pada ujung A dan ujung B.

3

Potong Kabel

Rapikan dan potong ujung kabel menggunakan tang crimping agar panjangnya sama.

4

Masukkan ke RJ45

Masukkan delapan kabel ke dalam konektor RJ45 sesuai urutan warna.

5

Kunci RJ45

Gunakan tang crimping untuk mengunci RJ45 pada kedua ujung kabel.

6

Uji Kabel

Hubungkan kabel ke LAN Tester. Jika lampu menyala sesuai urutan, kabel siap digunakan.

Koneksi Peer to Peer

Menghubungkan dua laptop menggunakan kabel LAN crossover

1

Siapkan Dua Laptop

Siapkan dua laptop dan satu kabel LAN crossover yang sudah dibuat.

2

Hubungkan Kabel

Hubungkan kabel crossover ke port Ethernet pada Laptop 1 dan Laptop 2.

3

Buka Pengaturan Ethernet

Control Panel → Network and Internet → Network and Sharing Center → Change adapter setting.

4

Atur IPv4

Klik Ethernet → Properties → Internet Protocol Version 4 (TCP/IPv4).

💻 Laptop 1

IP Address:

198.168.10.1

Subnet Mask:

255.255.255.0

💻 Laptop 2

IP Address:

198.168.10.2

Subnet Mask:

255.255.255.0

Windows + R → ketik CMD


Ping Laptop 1:

ping 198.168.10.1


Ping Laptop 2:

ping 198.168.10.2


Jika mendapatkan Reply, koneksi berhasil.

Sharing File

Berbagi dokumen dari Laptop 1 ke Laptop 2

1

Pilih File

Cari file atau folder yang ingin dibagikan pada Laptop 1.

2

Give Access To

Klik kanan file → Give access to → Specific people.

3

Pilih Everyone

Pilih Everyone → Add → Permission Level Read/Write.

4

Share

Klik Share kemudian pilih Done.

5

Buka dari Laptop 2

Tekan Windows + R kemudian masukkan alamat komputer yang melakukan sharing.

Windows + R

\\192.168.10.1


Setelah terbuka, masuk ke folder/file yang dibagikan kemudian copy file tersebut ke folder Documents Laptop 2.
